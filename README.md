# 🔥 Fire Up The Grill – Food Ordering Web App

A modern and dynamic **food ordering web application** built with React to strengthen core frontend development skills and simulate real-world application behavior.

---

## 📌 Project Overview

This project focuses on building a **scalable and dynamic frontend application** using modern React concepts. It demonstrates how real-world food ordering platforms manage data, routing, and user interactions efficiently.

All data is managed through structured JSON and rendered dynamically across multiple pages, ensuring flexibility and maintainability.

---

## 🛠️ Tech Stack

* ⚛️ React
* 🔁 React Router DOM
* 🎨 Tailwind CSS
* 🌼 DaisyUI
* 🌐 Context API

---

## ✨ Key Features

* ⚡ **Lazy Loading** with React Router for better performance
* 🧭 **Client-side Routing** for seamless navigation
* 📦 **Dynamic Data Rendering** from JSON
* 🧠 **Global State Management** using Context API
* 🔁 **Custom Hook (`useCartHooks`)** for reusable logic
* 🛒 **Add to Cart System** with centralized state
* 🔢 **Quantity Increment & Decrement** functionality
* 💰 **Dynamic Order Summary** (subtotal, tax, total updates in real-time)
* 🧩 **Reusable Components** (cards, categories, modals)
* 🔍 **Interactive Modal View** for product details
